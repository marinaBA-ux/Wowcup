# 🎾 WOW Cup Ticket Monitor

Бот автоматически проверяет страницу продажи билетов на **WOW Cup** и отправляет уведомление в Telegram, если обнаруживает возможное изменение статуса билетов.

## Как работает бот

При каждом запуске бот:

1. Открывает официальный сайт WOW Cup:

   ```
   https://wowcup.tennis/
   ```

2. Находит кнопку **«Купить билет»**.

3. Нажимает кнопку и открывает страницу билетного сервиса.

4. Определяет, какой билетный сервис открылся:

   * Яндекс Афиша;
   * или другой сервис.

5. Получает текст страницы и проверяет наличие известных сообщений:

   * о том, что билеты проданы или закончились;
   * о технической ошибке.

6. Если известные сообщения об отсутствии билетов исчезли, бот считает это **возможным изменением статуса** и отправляет уведомление в Telegram.

---

## Логика проверки

### 🎫 Билеты отсутствуют

Бот не отправляет уведомление, если на странице обнаружено одно из сообщений:

* `билеты проданы`
* `билетов нет`
* `билеты закончились`
* `распродано`
* `sold out`
* `no tickets`

### ⚠️ Техническая ошибка

Бот также не отправляет уведомление, если обнаружены признаки технической ошибки:

* `код ошибки`
* `ошибка загрузки`
* `страница недоступна`
* `что-то пошло не так`

В этом случае в логах будет указано, что статус билетов определить невозможно.

### 🚨 Возможное изменение статуса

Если на странице:

* нет известных сообщений о продаже билетов;
* нет известных сообщений о технической ошибке;

бот отправляет уведомление в Telegram:

> 🎾 WOW CUP — ВОЗМОЖНО, ИЗМЕНИЛСЯ СТАТУС БИЛЕТОВ!

Это **не гарантирует**, что билеты действительно появились. Бот сообщает, что содержимое страницы изменилось и требует ручной проверки.

```text
🎾 WOW CUP — ВОЗМОЖНО, ИЗМЕНИЛСЯ СТАТУС БИЛЕТОВ!

Проверить билеты:
[ссылка на страницу билетного сервиса]

```

## Настройка

Для работы бота необходимо создать Telegram-бота и указать следующие секреты:

### `TELEGRAM_BOT_TOKEN`

Токен Telegram-бота.

### `TELEGRAM_CHAT_ID`

ID чата, в который будут отправляться уведомления.

В GitHub Secrets:

```text
Settings → Secrets and variables → Actions
```

Добавьте:

```text
TELEGRAM_BOT_TOKEN
TELEGRAM_CHAT_ID
```

## Локальный запуск

Установите зависимости:

```bash
pip install -r requirements.txt
```

Установите браузер для Playwright:

```bash
playwright install chromium
```

Задайте переменные окружения:

```bash
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
```

Запустите монитор:

```bash
python monitor.py
```

## Важные особенности

* Бот начинает проверку с официального сайта WOW Cup.
* Не используется заранее сохранённая ссылка на билетный сервис.
* При каждом запуске бот заново нажимает кнопку **«Купить билет»**.
* Если организаторы изменят билетный сервис, бот попытается выполнить универсальную проверку новой страницы.
* Если страница не содержит знакомых сообщений об отсутствии билетов или технической ошибке, будет отправлено уведомление для ручной проверки.

## Ограничения

Бот определяет изменение статуса по тексту страницы.

Поэтому возможны ситуации, когда:

* билетный сервис изменит формулировку сообщения;
* появится новая техническая ошибка;
* страница изменит структуру;
* бот отправит уведомление, хотя билеты ещё фактически недоступны.

Поэтому любое уведомление рекомендуется проверить вручную по ссылке, которую прислал бот.
