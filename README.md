# Telegram-бот для отслеживания билетов Яндекс Афиши

Бот открывает указанную страницу в Chromium примерно каждые 10 минут и отправляет Telegram-сообщение, когда обнаруживает признаки доступной покупки.

## Важно
- Это стартовая версия с эвристической проверкой текста страницы. Яндекс может менять виджет, поэтому после первого запуска нужно проверить, что бот правильно распознаёт состояния «нет билетов» и «купить».
- Проверка раз в 10 минут не гарантирует мгновенное уведомление.
- Не публикуйте токен Telegram-бота и не добавляйте его в этот проект.
- Для круглосуточной работы нужен постоянно работающий компьютер или облачный хостинг с поддержкой Docker и фоновых процессов.

## 1. Создать Telegram-бота
1. В Telegram откройте `@BotFather`.
2. Отправьте `/newbot` и следуйте инструкциям.
3. Сохраните выданный токен в секрете. Не отправляйте его в чат.

## 2. Запустить локально
Нужны Python 3.11+ и установленный Docker либо Playwright.

### Через Docker
В папке проекта выполните:

```bash
docker build -t afisha-ticket-bot .
docker run -d --name afisha-ticket-bot \
  -e TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН" \
  -e CHECK_INTERVAL_SECONDS="600" \
  -v "$(pwd)/data:/app" \
  afisha-ticket-bot
```

Если запускаете не через Docker:

```bash
pip install -r requirements.txt
playwright install chromium
```

Linux может потребовать системные зависимости Playwright; команда `playwright install --with-deps chromium` установит их на поддерживаемых Linux-системах.

Задайте переменную окружения `TELEGRAM_BOT_TOKEN` и запустите:

```bash
python main.py
```

## 3. Подключить Telegram
1. Откройте своего нового бота по имени, которое задали в BotFather.
2. Нажмите Start или отправьте `/start`.
3. Бот начнёт проверять страницу.
4. Отправьте `/status`, чтобы посмотреть последнее состояние.

## Настройки
- `CHECK_INTERVAL_SECONDS=600` — 10 минут. Можно указать `300` для 5 минут, но частые запросы могут быть ограничены сайтом.
- `TARGET_URL` — ссылка на конкретную сессию.
- `STATE_FILE` — файл состояния, по умолчанию `state.json`.

## Что важно проверить после запуска
Проверьте `/status` в ситуации, когда билетов нет. Когда продажа откроется, убедитесь, что уведомление пришло. Если бот ошибочно считает билеты доступными или не замечает их, потребуется подстроить маркеры в функции `inspect_page()` под фактический текст виджета.
